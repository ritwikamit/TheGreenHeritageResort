# SXO: Search Experience Optimisation

The site should help a visitor answer three questions quickly: what the property offers, where it is, and how to enquire.

## Key actions
- Place Contact, Directions and Enquire actions where visitors can find them.
- Keep the enquiry form short.
- Show the exact location and a working map link.
- Explain that an enquiry is not a confirmed reservation.
- Offer a direct phone/WhatsApp alternative if the form fails.
- Display only verified services, rates, facilities and policies.

## Trust and clarity
Use actual property photographs and consistent contact information. Avoid fake urgency, unsupported superlatives, invented testimonials and hidden charges. Explain how visitors can confirm availability and booking terms.

## Accessibility
Use semantic headings, visible keyboard focus, accessible labels, clear error messages, adequate contrast and reduced-motion support. Test mobile navigation and gallery controls with keyboard and screen reader checks.

## Performance
Aim for Core Web Vitals targets of LCP <= 2.5 seconds, INP <= 200 ms and CLS <= 0.1. Measure after deployment; these are targets, not guarantees.

## Conversion measurement
Track clicks on phone, WhatsApp, directions and form submissions without collecting personal form contents in analytics.
