# QA and Launch Checklist

## Business details
- [ ] Official business name confirmed.
- [ ] Address and map pin confirmed.
- [ ] Primary phone, WhatsApp and email confirmed.
- [ ] Opening hours confirmed.
- [ ] Stay/event services and facilities confirmed.
- [ ] Prices, capacity, room details and policies verified or omitted.
- [ ] Image and testimonial permissions documented.

## Functionality
- [ ] Navigation and all CTAs work.
- [ ] Phone, WhatsApp, social and Maps links are correct.
- [ ] Enquiry form validates on client and server.
- [ ] Email delivery tested.
- [ ] Rate limiting and spam controls tested.
- [ ] Success and error states are accessible.
- [ ] Broken links and 404 behaviour checked.

## Security
- [ ] HTTPS and redirects verified.
- [ ] No secrets in Git, frontend bundles or logs.
- [ ] Production environment variables secured.
- [ ] Security headers tested.
- [ ] Dependency and secret scans reviewed.
- [ ] Oversized/malformed payloads and rate limits tested.
- [ ] Errors reveal no stack traces or private information.
- [ ] Privacy notice and retention process approved.

## SEO and performance
- [ ] Titles, descriptions and canonical URLs are correct.
- [ ] Sitemap and robots.txt checked.
- [ ] Structured data matches visible verified facts.
- [ ] Preview deployment is not indexed.
- [ ] Images compressed and responsive.
- [ ] Mobile performance checked.
- [ ] Search Console configured.

## Release
- [ ] Domain and DNS verified.
- [ ] Production enquiry delivery tested.
- [ ] Uptime/error monitoring enabled.
- [ ] Rollback plan documented.
- [ ] Owner has required access and maintenance instructions.
